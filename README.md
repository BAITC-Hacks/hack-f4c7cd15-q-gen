# finanse — аналитика банковских переводов

Проект команды для кейса «Граф денег». Python загружает данные о клиентах и переводах,
создаёт БД, определяет предварительные роли участников, выделяет сообщества и формирует
объяснимые аналитические отчёты.

## Скачать проект

**`finanse.zip`** — весь проект отдельным архивом. Архив подготовлен локально; загрузка в репозиторий пока ожидает авторизации GitHub для передачи ZIP.
Распакуйте его и откройте папку `finanse`.

Внутри: Python-код, исходные Parquet, SQLite и DuckDB, дашборд, CSV-отчёты,
описание методики и проверки. Виртуальные окружения и установленные зависимости
не включены — они устанавливаются через `requirements.txt`.

- Дополнительные сигналы: 288 крупных переводов по порогу Q3 + 3×IQR,
  177 пар со встречными переводами, 118 совпадений входа и выхода за день,
  98 всплесков активности. Сигналы могут пересекаться и требуют проверки.

## Запуск

Требуется Python 3.12.

```bash
cd finanse
python -m pip install --target .packages -r requirements.txt
python analyze.py
python db_analytics.py
python test_analysis.py
python test_db_analytics.py
python serve.py
```

Дашборд: **http://127.0.0.1:8765**.

Готовая SQLite-база: `database/bank.sqlite3`. Её можно читать через стандартный
модуль Python `sqlite3`. Для повторного создания укажите новое имя:

```bash
python create_database.py --db database/bank_new.sqlite3
```

Аналитические скрипты и дашборд используют `out/analytics.duckdb`.
SQLite — отдельная готовая база тех же исходных данных.

## Ограничения выводов

Граф собран по исходящим переводам от 81 клиента на глубину 4 шага, с порогом 5 000 ₸.
У seed-клиентов входящие неполны; у 444 клиентов на границе дальнейшие переводы неизвестны.
Роли определены объяснимыми правилами, а приоритет обозначает важность изучения,
не вероятность мошенничества. Анализ работает локально; масштабирование на миллионы
операций пока не проверялось. Подробная методика — в README внутри архива.

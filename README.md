# Поток — аналитика финансовых связей

Локальный интерфейс на HTML/CSS/JavaScript и Three.js: обзор, полная 2D/3D-сеть, участники, кластеры, хронологические цепочки и список проверки. Аналитические формулы и CSV-схемы сохранены.

**[Готовый обновлённый проект](potok-updated.zip)** · [Исходный код](finanse/) · [Инструкция](finanse/UI_GUIDE.md) · [Фактические проверки](finanse/VERIFICATION.md)

Из корня проекта:

```powershell
cd finanse
python -m pip install -r requirements.txt
python run.py --serve
```

Откройте **http://127.0.0.1:8765/**. Нужен Python 3.12+. Для установки в отдельное окружение см. инструкцию. После установки Python-зависимостей интернет не требуется: локальный Three.js и данные включены. Node.js нужен только разработчику для подготовки библиотеки и JavaScript-тестов.

Исходный `finanse.zip` сохранён как архив первоначальной версии. Не распаковывайте его поверх обновлённого кода.

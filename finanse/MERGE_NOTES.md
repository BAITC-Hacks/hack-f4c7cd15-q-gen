# Объединённая локальная сборка

Основа: GitHub 98a5c9b и предоставленный potok-updated.zip.
Новый интерфейс, локальные Three.js и 2D/3D соединены с FastAPI.
Сохранены недельные сравнения, повторяющиеся маршруты, PDF, темы и переключатель языка (перевод нового интерфейса частичный).
Исходные архивы и рабочая версия не перезаписывались. GitHub не изменён.

Запуск: `python run.py --serve --port 8766`.
Проверено: 46 Python-тестов, 6 JavaScript-тестов, 11 HTTP-маршрутов включая PDF.
Документы UI_GUIDE.md и VERIFICATION.md описывают исходный фронтенд; текущая интеграция описана здесь.

Добавлен командный Copilot из d1e14e2. Без ключа используется локальный ответ, внешний LLM не проверялся.

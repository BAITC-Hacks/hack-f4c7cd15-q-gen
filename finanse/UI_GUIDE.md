# Обновлённый интерфейс «Поток»

HTML/CSS/JavaScript и локальный Three.js. Правила ролей, формула приоритета, Louvain, поиск цепочек и CSV-схемы сохранены.

## Запуск

Из папки `finanse`, Python 3.12+:

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe run.py --serve
```

Если зависимости уже установлены в используемый Python, обычная команда остаётся прежней:

```text
python run.py --serve
```

Открыть **http://127.0.0.1:8765/**. Остановка — Ctrl+C. Другой порт: `--port 8767`. Просмотр готовых результатов без пересчёта: `python serve.py`.

Данные восстановлены из поставленного `finanse.zip`, результаты пересчитаны. Не распаковывайте старый архив поверх обновлённого кода. Актуальный архив — `../potok-updated.zip`.

Node.js и интернет не нужны при обычном запуске. Three.js 0.180.0, OrbitControls и лицензия включены в `vendor/`. Шрифт системный, иконки встроенные; внешних CDN и runtime-запросов к интернету нет.

## Разделы

| Адрес | Назначение |
| --- | --- |
| `/` | Показатели, полная сеть, топ-5, динамика, роли |
| `/graph` | Полная интерактивная сеть в 2D и 3D |
| `/analytics` | Участники, фильтры, числовая сортировка, страницы по 20 строк |
| `/analytics?view=clusters` | Сообщества, гипотезы, участники, переход к графу |
| `/routes` | Хронологический поиск цепочек |
| `/analytics?view=review` | Список проверки и серверный CSV |
| `/analytics?view=method` | Методика, реальные разборы, устойчивость при удалении узлов |
| `/analytics?view=controls` | Результаты контрольных сценариев |
| `/analytics?view=exports` | Существующие CSV-выгрузки |

Прямая ссылка: `/graph?gid=100000000331309100&hops=1&mode=3d`. Выбор, фильтры, режим, раскладка и сортировка находятся в URL. Навигация переносит их; обновление и «Назад» восстанавливают состояние. `gid`, `src`, `dst` остаются строками; числовые идентификаторы в API отклоняются как потенциально неточные.

Список проверки сохраняется в sessionStorage этой вкладки: максимум 50 уникальных клиентов. Экспорт использует исходный `/download/review.csv` с серверной валидацией.

## Управление графом

- 3D: левая кнопка — вращение, правая — перемещение, колесо — масштаб. Автовращения нет. Есть кнопки масштаба, всей сети, вида сверху и сброса камеры.
- 2D: перетаскивание — перемещение, колесо — масштаб. Canvas 2D работает без WebGL.
- Поиск использует полный gid, включая изолятов. Для скрытого фильтрами клиента предлагается сбросить фильтры и показать его.
- Окружение: 1–2 перехода. «Все связи» обходит сеть без учёта направления, «Входящие» — против направления, «Исходящие» — по направлению. Стрелки всегда отражают исходные переводы.
- «По коленам»: пять слоёв depth 0–4; «По кластерам»: пространственные сообщества. Все реальные связи сохраняются, искусственные рёбра не добавляются.
- Размер узла ограничен и отражает приоритет. Толщина связи зависит от логарифма суммы. Встречные рёбра изгибаются в противоположные стороны, петля имеет отдельный контур.
- Кольцо обозначает seed, ромб — truncated_by_depth. Глубина показана отдельно. Нажатие на связь показывает src, dst, сумму и число операций.
- Карточка сохраняет исходные evidence и priority_evidence, факторы, временные сопоставления, ограничения и следующий запрос. Неопределённый pass-through подписан «Не определён».

## Модули и производительность

`ui/data.js` — загрузка и проверка контракта; `state.js` — URL, фильтры, окружение и список; `layout-core.js`, `layout-worker.js`, `layout.js` — детерминированная раскладка с кэшем; `scene3d.js`, `scene2d.js` — режимы отрисовки; `geometry.js` — направленные кривые; `card.js`, `controls.js`, `legend.js`, `shell.js` — интерфейс.

InstancedMesh используется для сфер, сегментов рёбер, стрелок, колец и маркеров границы: пять вызовов отрисовки для полного графа. Подписи ограничены, пересекающиеся скрываются. Кадр запрашивается только при изменении камеры, данных или размеров; постоянной симуляции нет. ResizeObserver реагирует на открытие карточки. Уничтожение освобождает геометрию, материалы, инстансы, обработчики, worker и WebGL-контекст.

Подготовка локальной библиотеки нужна только при обновлении её версии:

```powershell
npm ci
npm run vendor
```

При запрете PowerShell-скриптов используйте `npm.cmd`. Версия зафиксирована в package.json и package-lock.json. `scripts/vendor.mjs` копирует библиотеку и заменяет импорт OrbitControls на локальный. Сборки приложения нет.

## Проверки

```powershell
python -m unittest discover -v
npm test
```

Python: 15 исходных тестов и 3 HTTP-теста. JavaScript: реальные контрольные числа, точные gid, детерминированность, изоляты, фильтры, направленное окружение, встречные дуги и петли. HTTP-тесты проверяют allowlist, MIME, API, реальный пример цепочки, CSV и запрет произвольных файлов.

Для проверки fallback: `python scripts/fallback-server.py`, затем `http://127.0.0.1:8766/graph`. Тестовый сервер выдаёт реальные данные, а HTML-fixture запрещает создание WebGL-контекста; производственный сервер не меняется. Ожидается автоматический 2D с объяснением причины.

Фактические проверки и ограничения: [VERIFICATION.md](VERIFICATION.md).

Документация библиотеки: [InstancedMesh](https://threejs.org/docs/pages/InstancedMesh.html), [OrbitControls](https://threejs.org/docs/pages/OrbitControls.html).

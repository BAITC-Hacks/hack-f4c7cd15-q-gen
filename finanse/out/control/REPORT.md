# Контрольные сценарии

Синтетические контрольные примеры проверяют реализацию правил, а не точность ролей на реальных клиентах. Пороги выбраны авторами; координатор и качество кластеризации этим набором не оцениваются.

| Сценарий | Ожидаемая роль | Полученная роль | Проверка |
|---|---|---|---|
| Сбор с удержанием | consolidator | consolidator | PASS |
| Распределение | distributor | distributor | PASS |
| Транзит на следующий день | transit | transit | PASS |
| Операции одного дня | peripheral | peripheral | PASS |
| Выход через четыре дня | peripheral | peripheral | PASS |
| Неполный вход seed | peripheral | peripheral | PASS |
| Обрезанная граница | peripheral | peripheral | PASS |
| Получатель внутри выборки | terminal | terminal | PASS |
| Изолированный клиент | peripheral | peripheral | PASS |

Каждый сценарий проходит через Parquet, SQL-агрегации, временные признаки и основной классификатор.
Исходные искусственные графы — input/, полный результат — actual/. Они не смешиваются с банковской выборкой.
